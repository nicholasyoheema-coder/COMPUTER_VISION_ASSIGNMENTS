# Results

- `metrics/final_tracking_metrics.json`: selected tuned tracker results.
- `metrics/baseline_vs_tuned_comparison.csv`: baseline/tuned comparison.
- `metrics/baseline_vs_tuned_comparison.json`: same comparison in JSON.
- `figures/tracking_comparison.png`: tracking quality comparison.
- `figures/tracking_errors.png`: tracking error comparison.

The frame-level tracks CSV, source images, annotated frames and videos are
not included in this public package.
