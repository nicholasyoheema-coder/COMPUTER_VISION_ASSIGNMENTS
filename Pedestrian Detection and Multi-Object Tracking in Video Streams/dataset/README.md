# Dataset Instructions

Dataset sequence: MOT17-02-FRCNN

Dataset: MOT17 multi-object tracking benchmark.

The selected sequence contains 600 frames at 1920x1080 and 30 FPS.
The experiment uses active pedestrian annotations only:
MOT class 1 with active/confidence flag 1.

The sequence was obtained from the Hugging Face dataset mirror:
https://huggingface.co/datasets/ling1016/MOT17

The original benchmark frames and ground-truth files are not included.
Obtain the dataset and follow the official MOTChallenge terms.
