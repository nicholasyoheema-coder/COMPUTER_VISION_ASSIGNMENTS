# Model Weights

This project uses the pretrained Ultralytics YOLO11n COCO checkpoint, `yolo11n.pt`.

The checkpoint is not included in this repository. Ultralytics downloads it automatically when the detection script is run if it is not already available.

COCO class IDs verified:
- Bottle: 39
- Cup: 41
