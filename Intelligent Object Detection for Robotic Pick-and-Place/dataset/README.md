# Dataset Instructions

Dataset: Bottles and Cups Dataset

Kaggle identifier: `dataclusterlabs/bottles-and-cups-dataset`

Source: https://www.kaggle.com/datasets/dataclusterlabs/bottles-and-cups-dataset

The experiment used 100 images, of which 89 had matching XML annotations. These annotations contained 97 bottle objects and 20 cup objects.

The dataset metadata identified the license as `copyright-authors`. Original images and XML annotations are not included in this repository. Download the dataset directly from Kaggle and follow the dataset owner's terms.
